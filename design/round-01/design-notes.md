# TestForge 主界面视觉方向 · 第 01 轮设计说明

日期：2026-10-07 · 状态：**待用户选方向**
对比页：`style-explorer.html`（离线单文件，双击即开） · 输入：`manifest.json` + 三个候选 HTML

## 任务与靶子

- 用户任务：为 TestForge（AI 测试用例生成平台）的主界面首屏（仪表盘）做视觉方向探索，三种字体、配色、构图都不同的设计，放对比页由用户挑选。
- 首屏用户来看什么：平台运行全景——待办、核心指标、服务状态、下一步动作（人审 / 回归 / 生成）。
- 品类与标杆：开发者质量工具 / B2B 工程平台。标杆参照 Linear（克制的暗色）、Grafana（数据密集）、以及品类套路"左侧栏 + 顶栏 + 卡片网格"本身——三个候选全部不用这套套路。
- 设备约束：桌面 1280×900 优先（对比页默认桌面视口）；现状基线为运行中的真实前端。

## 数据口径（诚实性）

基线 = `http://localhost:5173/?view=dashboard` 实时运行（用户浏览器有登录态；新环境点一次"一键登录"）。

## 三个方向卡

### A · 质检日报（a-report.html）

| 字段 | 取值 |
| --- | --- |
| 北极星 | 用起来像在签发一份正式的质量检验报告——每个数字有编号、日期和责任栏，质量即准出、不合格不出厂 |
| 生成引擎 | 历史媒介并置：把抽象的 AI 测试平台放进"工厂质检报告 / 公文"这份有历史厚度的媒介（产品本就有准出报告、G0–G5 关卡） |
| 调性 | 安静 · 精致 · 中密 · 庄重（公文） |
| 首屏骨架 | 无侧栏单列公文流：双细线报头 → 居中导航 → 批注待办栏 → 台账式指标 → 条款流水线 → 印章关卡 → 执行账目表 |
| 字体 | 宋体报头/章节题（SimSun 700）+ 微软雅黑正文 + Consolas 等宽数字；章节用"一、二、三、四"条款编号；批语用楷体 |
| 色彩 | 暖纸白 #f7f4ec / 墨黑 #211d14 / 朱砂印红 #b23a26（≤8%，只给印章、圈注、失败态）/ 灰 #6f695a |
| 主视觉 | G0–G5 质量关卡画成"检验通过"朱砂印章（双圈 + 微旋转） |
| 记忆点 | 批注栏的红笔圈数字（超限红圈、归零灰圈）；页边竖排批语"质量即准出 · 不合格不出厂" |
| 结构性突破 | 抛弃后台"侧栏 + 卡片网格"，首屏是一份摊开的报告文档流 |
| 放弃什么 | 不用渐变、不用阴影卡片、不用彩色状态灯——状态全部交给文字与印章 |

### B · 蓝晒图纸（b-blueprint.html）

| 字段 | 取值 |
| --- | --- |
| 北极星 | 用起来像趴在一张被测系统的覆盖图纸上——模块是线稿块，覆盖率是尺寸标注，缺陷是审图红笔的圈点 |
| 生成引擎 | 材质 × 环境：晒图纸 × 制图桌（测试用例是代码诞生前的工程图纸） |
| 调性 | 安静偏冷 · 精致 · 密 · 严谨（工程制图） |
| 首屏骨架 | 整面制图画布：双线图框 + 四角对位标记 → 图签标题栏 → 图号导航 → 左标注栏（尺寸线 KPI + 图例）+ 右覆盖图（模块块 + 引出线 + 剖面管线）→ 右下图签栏 |
| 字体 | 等宽主导（Consolas，标签全大写 0.2em 字距）+ 雅黑说明文字；红笔批注用楷体手写感 |
| 色彩 | 普鲁士蓝 #0c2340 底 / 图纸白 #dce9f8 线稿 / 制图蓝 #7fa4cf / 审图红 #ff6f61（只给批注与缺陷热点） |
| 主视觉 | 覆盖图纸：真实函数块（verify_password 30.0%、tokenize 10.6%…）+ 带箭头的尺寸标注线 |
| 记忆点 | 覆盖率画成尺寸线；楷体红笔批注圈"草稿 39"；右下角制图图签栏（编制 AI PIPELINE / 审核 草稿 39） |
| 结构性突破 | 无卡片网格，首屏是一张完整制图画布，导航变成图签 |
| 放弃什么 | 不用彩色层级区分（单色蓝系 + 红笔），不用圆角、不用填充色块 |

### C · 炉前控制台（c-forge.html）

| 字段 | 取值 |
| --- | --- |
| 北极星 | 品牌名 Forge 就是熔炉：像站在炉前看仪表——炉子烧着什么、出了多少炉、合格率多少，一眼扫完 |
| 生成引擎 | 角色原型 / 品牌直译：TestForge = 测试锻造炉，生成过程即锻造（需求投料 → 高温加工 → 用例出炉） |
| 调性 | 喧闹偏工业 · 硬朗 · 密 · 重（极端方向：各项都取重的一端） |
| 首屏骨架 | 不对称控制台：粗黑顶栏（状态灯排 + 铭牌式导航）→ 左 58% 炉况大面板（阶段管线 + 熔橙炉温刻度 + 燃烧日志 + 队列）+ 出炉记录，右 42% 超限数据塔 + 库存 |
| 字体 | 特黑工业无衬线（雅黑 900 大标题）+ Consolas 超大等宽数字（74px 炉温 / 42px 计数塔）；全大写字距标签 |
| 色彩 | 炭钢 #131418 / 面板 #1d2026 / 热白 #ece7dc / 熔炉橙 #ff6a1a（渐变只给"燃烧中"的元素）/ 预警黄 / 合格绿少量 |
| 主视觉 | 炉温刻度条：78% 熔橙渐变填充 + 呼吸发光（CSS keyframes），旁边 74% 大数字 |
| 记忆点 | "超限自动亮橙"的数据塔（草稿 39 / 缺陷 21 亮橙）；失败运行左缘熔橙条；"锻造中"脉冲章 |
| 结构性突破 | 卡片网格 → 不对称双栏控制台 + 大数字塔；面板切角（clip-path）替代圆角 |
| 放弃什么 | 不用圆角卡片和浅灰底；状态不用小圆点标签，全部放大成可扫读的量 |

## 差异检验（已通过）

- 首屏骨架：单列公文流 / 全画布图纸 / 不对称控制台——三种结构，眯眼看明暗块面分布完全不同。
- 字体：宋体报告体 / 等宽制图体 / 特黑工业体——三种文字性格。
- 色彩身份：暖纸+墨+朱红 / 普鲁士蓝单色系+审图红 / 炭钢+熔橙——三个色相族，非明暗区分。
- 主视觉：印章 / 尺寸标注图纸 / 炉温刻度——互不重复。
- 品类套路：三个都打破了"侧栏 + 顶栏 + 卡片网格"；C 走到极端（重、密、工业）；无撞脸（现状 AntD 靛蓝渐变恰好是被规避的行业默认）。

## 动效口径

探索阶段小样为纯 HTML + CSS（对比页不执行脚本，CSS 动画仍存活）：A 空闲态静、B 红笔圈呼吸、C 炉温呼吸发光 + 状态灯脉冲 + 锻造中脉冲。三处基本动效（悬停反馈、状态切换、数据进场）在方向选定后的实现阶段按 motion.md 落地并录屏取证。
