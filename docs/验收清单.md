## 已知边界说明

1. `SANDBOX_MODE=docker` 真实容器沙箱按规范实现；默认 local 子进程真执行；
2. webhook 默认局域网信任模式（`WEBHOOK_SECRET` 为空不校验），公网部署必须设置；

4. PRD 的 Kafka 异步事件以 trace 事件 + 任务队列等价实现，compose 预留扩展位。
