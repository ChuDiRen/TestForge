## 已知边界说明

1. `SANDBOX_MODE=docker` 真实沙箱按规范实现（--network none / mem 512m / cpu 1.0，`deploy/sandbox.Dockerfile` 自动构建），本机验证走 fake/local 模式；
2. LLM real 模式（OpenAI 兼容）已接全管线，本验收在 mock 模式（确定性输出，保证可复现）；
3. PRD 的 Kafka 异步事件（契约变更通知）以 trace 事件 + 同步 gRPC 等价实现，compose 预留扩展位；
4. `GET /api/generations/{id}/events` SSE 经 WSL localhost 转发在部分环境可能缓冲，前端工作台同时支持轮询降级。
