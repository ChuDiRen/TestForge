## 1. 产品定位与原则

**AI 智能体驱动的测试用例生成平台**：需求是源头，知识预编译，AI 深度代理生成四层用例（单元/功能/接口/E2E），真实沙箱验证闭环，全链路引用溯源。

四条产品原则（违反即缺陷）：

1. **无 mock 原则**：不存在任何确定性假实现。LLM 真实调用，沙箱只有真实执行，期望值来自真实代码执行捕获。
2. **现实即规格**：LLM 只设计输入与场景；断言期望值由探针对真实代码执行捕获并**反向校正**（LLM 猜错的断言一律被真实结果覆写）。
3. **诚实台账**：失败建缺陷、覆盖率如实显示、打回如实扣分；探针无法观测的断言诚实剔除而非编造。
4. **智能体驱动（v3.0 新增）**：AI 助手是平台的主操作入口——四层生成、知识收集、质量查询都在对话中完成；表单页面是精确操作的补充而非替代。

## 2. 系统架构（as-built）

- **形态**：单体优先（`MONO=1`，7 服务进程内直调，仅暴露网关）；保留微服务拓扑切换位。
- **后端**：Python 3.13 + FastAPI gateway + 7 个 gRPC 服务（repo / wiki-builder / contract-registry / req / testgen / runner / trace）。
- **前端**：React 18 + TS + Vite + AntD 5 + React Query + ECharts（`frontend/` 与 `backend/` 顶层分离）。
- **存储**：PostgreSQL 16 + pgvector。
- **LLM**：OpenAI 兼容接口（默认 DeepSeek；`LLM_BASE_URL` 可指向内部网关/vLLM 私有化——公司落地 LLM 不出域，见 §9）。
- **智能体框架**：**deepagents 0.7（langgraph）**——领域工具 + 内置文件工具（grep/glob/ls/read_file，FilesystemBackend 锁定仓库检出）+ execute 执行沙箱 + 跨会话记忆 + 长对话自动摘要。
- **执行沙箱**：thread-scoped（每会话 `data/assistant_sandbox/thread-N/`）+ 环境变量白名单（宿主机 .env 密钥不透传）+ 超时 180s + 输出截断 + `/repo/` 只读挂载；测试执行另有 runner 沙箱（local 子进程 / docker 容器 `--network none`）。
- **任务队列**：jobs 表持久化 + 进程内 worker（`FOR UPDATE SKIP LOCKED`，崩溃重排队）。
- **认证**：PBKDF2（100k 轮）+ HMAC token（12h 滑动续签）+ 登录限速（IP 60s×5 / 账号 15min×10 锁定）+ admin/viewer 角色 + `ENV=prod` 启动安全检查（默认密钥/沙箱未容器化等五项直接拒启）。

## 3. 核心用户动线（v3.0）

```
仪表盘（空库=四步快速开始 / 有库=待办直达）
  ├─ AI 助手（菜单第一项·主入口）：对话生成四层用例 / 贴文档入库 / 查质量
  ├─ 知识资产：仓库接入 → 代码库/Wiki（+上传文档） → 知识图谱 → 服务地图/契约
  ├─ 测试流程：需求录入（可测性评分）→ 测试计划 → 生成工作台（四层表单）→ 任务队列
  └─ 质量运营：用例库（文件预览）→ 执行记录 → 缺陷管理 → 质量流水线 → 日志/追溯
```

- 每个关键操作完成后有 **NextStep 引导**（接入成功→看 Wiki/去生成；需求生效→去工作台；生成完成→去用例库）。
- 无状态 token 过期、AI 引用标签（`[[路径:行]]`/`[[Function:x]]`）点击直达对应页面。

## 4. 四层用例生成（核心能力，实测达标）

| 层 | 规划来源 | 执行 | 实测入库率 |
|---|---|---|---|
| **ut 单元** | deepagents 智能体自主探索（精选/探针名单走确定性路径） | 沙箱 pytest + 分支覆盖 | **97%**（61/63） |
| **fn 功能** | 同 ut 管线，按业务场景语义出主流程/边界/异常/权限用例（layer=fn 归档） | 同上 | **100%**（39/39） |
| **api 接口** | 运行中网关实时 OpenAPI 契约推导（健康/鉴权/401/404/参数校验） | httpx 真实请求 | **100%**（6/6） |
| **e2e 端到端** | 平台真实服务旅程（token 传递、跨步骤数据绑定） | 跨端点调用链 | **100%**（2/2） |

生成质量的三道保障（v3.0 优化实录：用例级入库率 63% → 97%）：

1. **探针（现实即规格）**：对真实代码执行捕获期望值，双跑一致性校验；**反向校正** LLM 错误断言（成功路径误配 raises 一律清掉，真实异常类名如实回填）。探针 import 兼容 `backend/` 重构布局。
2. **固定时钟**：探针与渲染测试统一 `time.time=1700000000`（autouse fixture）——时间/HMAC 依赖函数（token 签发类）的断言完全可重放。
3. **形状容错**：LLM 输出漂移（patches 收到 dict、str 字段收到 list）不再炸规划；空打桩不渲染非法 Python；探针捕获的异常类（GitError 等）自动从被测模块导入。

已知边界：强时间/随机依赖且无法固定时钟的函数，探针按双跑一致性诚实剔除（不造假）。

## 5. AI 助手（智能体驱动，v3.0 核心）

- **定位**：平台主操作智能体（菜单第一项）。四层生成的对话式入口——解析层别、确认目标、调工具入队、汇报任务号。
- **工具面（12+）**：领域工具 search（混合检索）/ explore（知识图谱）/ read（源码）/ impact（影响面）/ overview（概览）/ cases（用例）/ **generate_case（四层生成，api/e2e 无需函数名）** / **create_requirement（四步解析管线）** / **upload_knowledge（文档入库即索引）**；deepagents 内置 grep/glob/ls/read_file（`/repo/` 只读）与 execute（沙箱）。
- **强制引用溯源**：每个结论带 `[[路径:行]]`/`[[Function:x]]`，前端渲染为可点击标签直达对应页面；无证据明说，禁止编造。
- **数据主动收集**：上下文不足时主动引导用户提供 PRD/接口约定/业务规则；用户贴文档即调 upload_knowledge 入库进索引（Wiki 页亦有表单入口）。
- **跨会话记忆**：`/memory/memory.md` 注入系统提示，模型 edit_file 沉淀项目约定/用户偏好，越用越懂团队（实测：教两条团队约定，新会话准确复述并标注来源）。
- **长对话保护**：接近上下文上限自动摘要压缩（深调查 18+ 工具轮次不爆）。
- **流式协议**：SSE 五类事件（token / tool_start / tool_end / done / error），前端工具时间线实时展示参数与耗时。

## 6. 知识资产（GitNexus / LightRAG 借鉴全面落地）

- **混合检索**：pgvector 向量 + PostgreSQL tsvector 双路召回，RRF 融合；批量原子索引（copy-and-swap）。
- **文档知识图谱**：Wiki/需求/缺陷实体关系抽取（LLM 角色路由 + 持久缓存），local/global/mix 三模式查询。
- **代码变更影响面**：git diff 行级 hunk + tree-sitter 归因，调用图反向 BFS blast radius（置信度随深度衰减）。
- **测试域聚类**：Louvain 社区发现，按调用耦合自动划分测试域。
- **契约中心**：注册（proto/openapi）/ diff / breaking 检测 / 受影响用例重生成 / 跨仓消费方匹配。
- **RAG 质量评估**：黄金集 CLI（混合 vs 向量单路对照）。
- **MCP Server**：知识能力对外暴露（`make mcp`）。
- **文档状态追踪**：index/wiki/kg/fts/rag 各环节 pending/ok/failed 台账。

## 7. 质量闭环（不变 + 强化）

需求录入（可测性 <80 自动打回）→ 确认生效自动编排 → 四层生成（探针校正 + 覆盖守卫补类 + 沙箱失败 RegenerateAffected 真回填重生成 ≤3 轮）→ 真实执行（junit + coverage）→ 失败自动建缺陷（四向关联 + AI 修复建议 + 定向回归）→ pull 变更驱动 stale → 自动回归自愈 → G0~G5 门禁（真实查询）。

同仓库+同目标+同层重新生成时旧用例置 `已替换`（历史可查）；用例详情为**文件形态**（IDE 风格预览 + `.py` 下载 + `/api/cases/{code}/file` 端点）。
